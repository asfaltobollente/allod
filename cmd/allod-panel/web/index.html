Benvenuto su Allod — Configurazione Iniziale Boot 24/7

Garantisci la persistenza di tutti i servizi e dei container Podman anche dopo il riavvio del server

Allod e Podman operano in modalità rootless per la massima sicurezza. Su Ubuntu, i container utente (Immich, Nextcloud, Samba) e la dashboard necessitano dell'abilitazione del linger e del servizio systemd per ripartire in autonomia all'accensione della macchina senza bisogno di login SSH.

⏳ Systemd User Linger (Container 24/7)
⏳ Servizio allod-panel (Web UI al Boot)
💻 Oppure esegui manualmente via CLI sul server: 
loginctl enable-linger $USER
mkdir -p ~/.config/systemd/user
cp ~/allod/configs/allod-panel.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now allod-panel
